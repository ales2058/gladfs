
Запуск: `gladfs.exe`. Пароль тома `volpass1`, вход `root / rootpass1`
(на свежесозданном диске — свои, format спросит сам).

```
--- 1. Диск и структура  ---
df                          → том, шифрование, блоки, каталоги
fmap                        → видно суперблок, FAT, каталог, дырки
ls                          → каталог: владелец, права, блоки

--- 2. Каталоги  ---
mkdir docs / mkdir docs/2026
cd docs / pwd               → приглашение сменилось
create report.txt / write report.txt Отчет...
ls / ls /docs/2026          → и относительные, и абсолютные пути
cd ..                       → относительная навигация
blocks docs                 → каталог — это ФАЙЛ с цепочкой блоков

--- 3. Обращение к месту на диске + шифрование ---
hexdump 0                   → сигнатура GLADFS1, геометрия
hexdump 1                   → FAT: FFFE у служебных, цепочки, свободные
hexdump docs                → содержимое каталога на диске — ШИФРОТЕКСТ:
                              даже имена файлов внутри не видны
cat report.txt              → а здесь всё читается (расшифровка на лету)
debug crypto                → шифр проходит официальные тест-векторы

--- 4. Пользователи и права  ---
whoami / users              → root, администратор
chmod docs/ 700 …           → права на каталог
exit → запуск снова → volpass1 → вход guest / guest123
cd docs → create x.txt      → ОТКАЗАНО: нет прав на запись в каталог
chmod вернул 777 → create   → теперь можно (права каталога-родителя)

--- 5. Корзина  ---
rm report.txt               → перемещён в корзину
trash                       → лежит, цепочка FAT цела
restore report.txt          → вернулся без потерь
rm report.txt -w            → удалён с затиранием нулями (безвозвратно)

--- 6. Подмена данных и восстановление  ---
blocks docs/2026/old.txt    → например блок 29
debug write 29 0 AB         → «подменили» байт данных на диске
cat docs/2026/old.txt       → ОТКАЗАНО: контрольная сумма не сошлась
fsck                        → называет файл по полному пути
write docs/2026/old.txt …   → новая запись обновляет сумму — файл читается
fsck                        → ошибок нет

--- 7. Персистентность  ---
exit → gladfs.exe → volpass1 → root/rootpass1 → ls /docs
                            → ВСЁ НА МЕСТЕ: данные живут на диске
```

Задание — каталог файлов в файловой системе. Список в ОЗУ пропадает при
выходе из программы; я сделал так, что «файлы» из постановки — настоящие
файлы на настоящем (виртуальном) диске: с адресацией блоков, деревом
каталогов, метаданными, шифрованием, правами, корзиной, защитой от подмены
и восстановлением после сбоев. Операции варианта №6 (вставка, удаление по
дате, максимум обращений) сохранены как команды ls/rmold/top.
